A FEW THINGS TO KNOW

궁금한 점을
먼저 살펴보세요.

지금 API를 호출할 수 있나요?

현재 API 제공을 준비 중입니다. 호출 주소·인증 방식·상세 데이터 규격은 확정 후 안내합니다.

가격표 대신 이용 방식을 안내하는 이유는 무엇인가요?

필요한 데이터와 활용 목적에 맞춰 제공 범위를 정하는 방식으로 준비하고 있습니다. 이용 조건은 제공 범위가 확정된 후 안내합니다.

메모를 만들면 문의가 접수되나요?

아닙니다. 메모는 이 화면에서 직접 확인하고 복사하는 용도이며 외부로 전송되지 않습니다. 문의 창구가 준비되면 별도로 안내하겠습니다.
